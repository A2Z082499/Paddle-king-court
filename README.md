# Court booking website

Static booking site (GitHub Pages) with a Supabase database.

| File | What it is |
|---|---|
| `index.html` | Customer booking page. Settings are in the `CONFIG` block at the top of its script. |
| `admin.html` | Owner page: log in, confirm or delete bookings, see who booked first. Settings in its `CONFIG` block. |
| `setup.sql` | One-file database setup. Edit the SETTINGS block, paste into Supabase, Run. |
| `SETUP-GUIDE.md` | Step-by-step guide for setting this up for a new client. |
| `logo.jpg`, `gcash-qr.jpg` | Add your own (same folder as `index.html`). |

Start with `SETUP-GUIDE.md`.
